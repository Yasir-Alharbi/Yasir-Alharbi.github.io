How to use Sirr safely

A notebook (case) remembers stable masked values so Sirr can restore answers later. Use one case per investigation and do not mix investigations in the same case.

Keep your passphrase: Sirr never stores it and cannot recover it. Export an encrypted backup regularly; it contains profiles and notebooks and uses the same passphrase.

For normal investigations, public IOC addresses remain visible. Enable “Mask all IPs” for whole logs when every address must change. Forgetting a case permanently removes its mapping, so its masked text can no longer be restored.
