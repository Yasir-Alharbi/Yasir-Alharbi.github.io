How to use Sirr safely
The Sirr file is plain-text Markdown and opens in Notepad. It holds real client names and the full real↔fake list, so keep it on this laptop and never upload or share it.
Type each client name once. Sirr recognizes joined forms and common company suffixes, then learns domains, computer names, and users while it masks. Review the Check these list after every mask: choose Hide to teach Sirr, or Keep for a safe value. The file uses ## Clients with client: name, plus learned values, cases, and your Keep list. Older ## Client: files still open and are saved in the new format.
A colleague opens the same Sirr HTML page and creates their own file on their own laptop.
